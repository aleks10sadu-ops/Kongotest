# Локальный редактор зон доставки

Самостоятельная Flask-страница для рисования и настройки зон доставки на карте. Редактор не читает и не изменяет файлы основного сайта.

## Запуск

```powershell
cd "tools\delivery-zone-editor"
py -m pip install -r requirements.txt
py app.py
```

Откройте [http://127.0.0.1:5123](http://127.0.0.1:5123).

## Как работать

1. Перетащите белые маркеры выбранного полигона или измените координаты справа.
2. Кнопка «Нарисовать» создаёт новую зону; двойной щелчок завершает полигон.
3. «Импорт» загружает `.geojson`/`.json` с `FeatureCollection` и полигонами, а также JSON-ответ Яндекс Vendor с массивом `coordinates` (`lt`/`lg`). После чтения файла редактор покажет список найденных зон: отметьте только нужные и подтвердите импорт. Выбранные зоны заменят текущий набор, а метки и линии из смешанного GeoJSON будут пропущены.
4. «Сохранить черновик» записывает состояние только в `data/delivery-zones.geojson` и создаёт локальную резервную копию в `backups/`.
5. «Экспорт GeoJSON» скачивает текущее состояние, включая ещё не сохранённые изменения.

## Формат GeoJSON

Каждая зона — `Feature` с геометрией `Polygon`. Координаты записываются по стандарту GeoJSON в порядке `[долгота, широта]`.

Поддерживаемые свойства:

```json
{
  "id": 1,
  "name": "Бесплатная доставка",
  "price": 0,
  "minOrder": 1000,
  "color": "#22c55e",
  "opacity": 0.3
}
```

Поиск адресов использует публичный Nominatim, а карта — тайлы OpenStreetMap, поэтому для них требуется подключение к интернету. Рисование, импорт, сохранение черновика и экспорт выполняются локально.

## Как забрать существующие зоны из Яндекс Vendor

В личном кабинете нет штатной кнопки экспорта. Откройте страницу нужного ресторана и раздел «Зоны доставки», затем:

1. Нажмите `F12` → `Network` (Сеть) → фильтр `Fetch/XHR`.
2. Обновите страницу и в строке фильтра введите `zone`.
3. Откройте запрос, в ответе которого есть `coordinates` и точки `lt`/`lg`.
4. На вкладке `Response` скопируйте весь JSON в файл с расширением `.json`.
5. Загрузите файл кнопкой «Импорт» в локальном редакторе.

Официальный интеграционный метод зон Яндекс Еды доступен только по подписке; инструкция выше использует только данные своего авторизованного кабинета.
